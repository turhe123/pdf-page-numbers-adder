How it works

  1. Open your PDF. Drop it on the page or pick it. The file is read in this browser tab and never uploaded.
  2. Place the numbers. Choose position, format, start number, font, size, margin and color. The page preview updates as you go; use the arrow keys to check other pages.
  3. Apply and download. Each page gets its label drawn with a standard PDF font, and you save a copy named yourfile_numbered.pdf. The original stays untouched.

Questions, answered

Are my files uploaded anywhere?

No. PDF Page Number Adder runs entirely in your browser. Your PDF is read into memory on your device, numbered with JavaScript, and never sent to a server. That matters for legal bundles, theses and contracts. You can disconnect from the internet and it keeps working.

Is it really free, and does it work offline?

Yes, it is free and open source under the MIT license, with no account, no ads, no hourly task limit and no page limit; the only limit is your device's memory. After your first visit the page is cached by a service worker, so it loads and works without a connection, and you can install it from your browser's menu as an app. If it saves you a paid subscription, you can say thanks on Ko-fi.

Can I skip the cover page or start from a different number?

Yes. Tick "Skip the first page", or set "First page to number" to start later in the document, and set "Start number" to any value (for example 10 to continue a previous volume). With "1 of N", N counts only the numbered pages, so a skipped cover does not make the total wrong.

Does it work with landscape, rotated or cropped pages?

Yes. The position is measured from the visible crop box, and on rotated pages the coordinates are turned so the number reads upright where you expect it. The preview is a simple outline of each page with the label drawn to scale, not a full rendering of its content.

Can it number password-protected PDFs or non-Latin text?

Encrypted PDFs are not supported; remove the password in the app that created the file first. Labels use the standard PDF fonts (Helvetica, Times, Courier), which cover Latin characters only, so the prefix field warns you about anything else.
